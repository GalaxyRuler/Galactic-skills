# Galactic Skills

Public skills for [Claude Code](https://claude.ai/code) — privacy-scanned and generalized for anyone to install.

## What are skills?

Skills are instruction files that extend Claude Code with domain-specific workflows. Install a skill and Claude knows how to handle that task type automatically.

## Installing a skill

```bash
# Via the skill-installer skill (if you have it)
/skill-installer <skill-name>

# Manually — copy the skill folder to your skills directory
cp -r <skill-name> ~/.claude/skills/
```
