# Templates, Deliverables & Checklists

The "produce output" toolkit. Every consulting task ends as one of these structured, copy-pasteable artifacts.

## Deliverable catalog

Startup Diagnostic Memo · Customer Discovery Plan · Validation Experiment Plan · Business Model Review · Market Sizing Memo · Competitor Analysis · MVP Scope Document · GTM Plan · Pricing Recommendation · Sales Playbook · Pitch Deck Critique · Fundraising Readiness Memo · Financial Model Review · Unit Economics Review · Operating Plan · Risk Register · 30/60/90-Day Action Plan.

## Response templates

### 1. Startup Diagnostic

```markdown
# Startup Diagnostic Assessment: [Venture Name]
## 1. Executive Summary
* Current Classified Stage: [1–10]
* Core Operational Bottleneck: [main constraint]
* Fundraising Status & Runway: [raised, net burn, months left]
## 2. Evidence Classification Audit
* Validated Facts: [...]
* Unverified Founder Claims: [...]
* Identified Source/Data Gaps: [...]
## 3. Structural Risk & Blind-Spot Analysis
* [Risk type — e.g., premature scaling / weak retention] — [impact & evidence]
## 4. Prioritized Recommendations
1. Immediate Stop Action: [stop doing now]
2. Validation Test: [falsifiable experiment]
3. Core Metric Focus: [single key metric this week]
```

### 2. Customer Discovery Plan

```markdown
# Customer Discovery & Problem Validation Blueprint
## 1. Target Account Profile (ICP)
* Target Entity Type: [size, vertical, geography]
* Target Persona (User): [title, responsibilities]
* Economic Buyer: [title, financial authority]
## 2. Behavioral Interview Script (Non-Leading)
* Workflow Context: "Walk me through how your team currently handles [process]…"
* Problem Discovery: "Last time [problem] happened, what was the impact?"
* Alternative Search: "What workarounds have you tried?"
* Financial Clue: "How much budget/effort did that workaround cost?"
## 3. Success & Invalidation Criteria
* Validation Gate: ≥[X]% rate this pain as a top-3 priority.
* Disqualification: polite praise but refuses to share data or book a follow-up.
```

## Readiness checklists

Use as gates before advancing a venture to the next phase.

**Idea Validation** — [ ] problem in one clear sentence · [ ] measurable financial/operational loss · [ ] specific ICP written · [ ] alternatives + workarounds + competitors mapped · [ ] assumptions documented and risk-ranked.

**Customer Discovery** — [ ] ≥20 interviews with cold target prospects · [ ] each focused on past behavior · [ ] purchase trigger isolated · [ ] economic buyer + user + approval loop mapped · [ ] >40% rate the pain top-priority.

**MVP Readiness** — [ ] hypothesis + invalidation trigger written · [ ] scope cut to minimum to test it · [ ] manual back-end plan before code · [ ] in-app analytics integrated · [ ] learning-experiment deadline set.

**Launch Readiness** — [ ] onboarding functional and frictionless · [ ] usage + retention tracking live · [ ] support channel active and owned · [ ] pricing in the checkout · [ ] core IP assigned to the entity.

**GTM Readiness** — [ ] value prop written as outcomes · [ ] 100 high-intent target accounts listed · [ ] outbound scripts, landing pages, tracking finalized · [ ] channel-experiment budget ceiling set · [ ] sales-cycle duration mapped from pilots.

**Fundraising Readiness** — [ ] ≥6 months runway before outreach · [ ] bottom-up model built and stress-tested · [ ] clean data room organized · [ ] vesting shareholder agreements signed · [ ] 18-month milestone plan ready.

**Pitch Deck Readiness** — [ ] intro states what the company does in one sentence · [ ] problem backed by hard data · [ ] market sizing bottom-up · [ ] traction shows cohort retention or signed agreements · [ ] final slide pairs ask with milestones.

**Financial Model Quality** — [ ] revenue from bottom-up inputs · [ ] salaries/hiring/hosting scale with volume · [ ] burn, runway, zero-cash date explicit · [ ] Base/Upside/Stress scenarios · [ ] every assumption documented with its logic.

**Scaling Readiness** — [ ] 90-day cohort retention flattened · [ ] fully loaded LTV/CAC ≥3:1 · [ ] payback <12 months · [ ] ops, sales playbooks, onboarding documented · [ ] architecture survives 10× volume.

## Completion criteria

Mirror the gates in [SKILL.md](SKILL.md): stage classified · bottleneck named · assumptions separated from evidence · existential risks flagged · recommendations linked to facts · 30/60/90 actions ranked · validation tests defined · metrics assigned · data gaps disclosed · professional-review boundaries stated with the disclaimer protocol.
